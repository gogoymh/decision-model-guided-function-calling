\subsection{Evaluation and Implementation}
\label{sec:data}
We evaluate 3,051 BFCL examples: simple Python (400), multiple (200), irrelevance (240), live simple (258), live multiple (1,053), live irrelevance (884), and live relevance (16). The AST checker compares names and arguments with allowed answers, not execution success. Irrelevance requires no call. Live relevance scores call presence only and is excluded from the 3,035-example main accuracy. Multiple means selecting among available functions; parallel, multi-turn, web-search, memory, and execution tasks are excluded.

Generators are \texttt{gpt-5-nano} (2025-08-07), \texttt{gpt-5.4-mini} (2026-03-17), and \texttt{claude-sonnet-5-5}. GPT uses reasoning effort \texttt{none}; Claude receives no thinking override. All use a 4,096-token output cap and automatic, nonparallel native tool choice. The decision model is \texttt{jev-1.13.0}; $r=3$ and $\tau_f=\tau_a=0.5$. These settings were chosen on the evaluated examples after thresholds 0.8/0.7 and last-candidate fallback; there is no held-out tuning set. Filtered or truncated generations count as incorrect.

For transfer, we adapt API-Bank~\cite{li2023apibank} to first-call prediction: retain dialogue prefixes before their first API turn and supply a fixed 53-API catalog, independent of gold calls. Eight gold/schema conflicts are excluded before inference, leaving 204 cases grouped into development (48) and test (156). A common user instruction requests a native call candidate without execution. We score API names and type-normalized arguments; this exact-match adaptation differs from API-Bank's native execution score. The BFCL settings transfer unchanged. Four development cases verify the interface, without tuning thresholds or fallback; the prompt was revised after inspecting earlier test outcomes, so this evaluation is exploratory.

\paragraph{Compared methods.}
All methods share initial candidates. \emph{Direct} returns the initial call; \emph{Schema repair} uses local errors; \emph{Self-refine} uses the generator's generic self-review for all $r$ repairs, an adaptation rather than a reproduction of Self-Refine~\cite{madaan2023selfrefine}. \textbf{DMGFC-F} uses only function feedback and its acceptance gate; \textbf{DMGFC-A} uses only argument feedback and its gate. Both compute applicable judgments but expose and require only their designated judgment, plus schema validation; DMGFC-A accepts no call on schema alone. \textbf{DMGFC-L} retains only the latest rejected candidate and feedback. Full \textbf{DMGFC} retains all records. F/A isolate the two checks; L isolates history retention with the same thresholds, budget, and initial calls.

\subsection{Main Experiment}
Table~\ref{tab:categories} shows BFCL gains of 10.7 points for nano (paired 95\% interval 9.7--11.6) and 1.0 for mini (0.5--1.5). Nano's largest category gain is on Irrelevance, 27.2\% to 78.2\%, driven by withholding unnecessary calls. Claude instead loses 1.3 points (interval $-1.8$ to $-0.7$): across three runs, repair fixes 58 initial errors but introduces 174 after accepted revisions. Its mean API time rises from 2.55 to 4.16~s.

API-Bank gains are 6.4 points for nano (interval 3.8--9.4), 1.3 for mini (0.2--2.6), and 0.9 for Claude (0.0--2.6). Claude's interval includes zero. These mixed effects do not establish a uniform benefit across generators or end-to-end tool-use success.

\subsection{Ablation and Latency}
In Table~\ref{tab:main}, both checks outperform either alone on call accuracy. Full history beats latest-only feedback by 1.1 points (95\% interval 0.4--1.7), with similar mean API time (2.61 vs.\ 2.60~s). DMGFC-A's higher conditional argument score does not imply better overall calls because the scored subsets differ.

\paragraph{Fallback and measurement limits.}
API time sums generation and verification, excluding retry waits, scoring, and tool execution. Cost includes initial and repair generation plus verification; unknown usage is omitted from known-cost means. Failed unsaved repair work is excluded, so costs are not invoice totals. Intervals bootstrap example IDs 2,000 times (seed 1729), averaging repetitions per ID. BFCL settings and API-Bank's input amendment followed inspected outcomes. API-Bank has only 156 test cases and no validated no-call negatives. Three generators, one verifier, single-run ablations, English-dominated public data, and ten retained BFCL annotation errors limit generalization. Native schema rejections count as incorrect. Claude BFCL concurrency changed from 8 to 32 with prefixes preserved; API times do not establish provider speed rankings. Acceptance and correctness remain separate.
