# 검증 기록

검증일: 2026-10-15

- 오프라인 테스트 108개가 통과했으며 Ruff 검사도 통과했습니다.
- BFCL 원본과 공식 AST 평가기는 고정된 버전 및 체크섬으로 준비했습니다. 총 3,051개를 개발 303개와 테스트 2,748개로 분할했습니다.
- 모델 요청에 정답, ID, 카테고리 또는 정답 유래 피드백이 포함되지 않도록 검증했습니다.
- 실제 LLM/Jev API 호출과 성능 실험은 실행하지 않았습니다. 모의 응답 및 합성 데모를 논문 실험값으로 사용하지 않았습니다.
- 기존 paper/main.tex의 내장 LaTeX 컴파일이 성공했습니다.
- 내보낸 PDF는 본문 4쪽과 참고문헌 1쪽으로 총 5쪽입니다. 필수 절과 인용 해소를 검사하고 모든 페이지를 시각적으로 확인했습니다.
- JEV-as-a-Judge: Accept When Confident, Escalate When Unsure의 arXiv v5 본문과 부록을 검토해 Related Work, 방법의 임계값 설명 및 참고문헌에 반영했습니다.
- 논문의 결과표는 미실행 값으로 남아 있습니다. 기본 전체 실험 후 make report로 표를 채우고, 실제 결과에 맞춰 abstract와 conclusion의 실증 해석을 수정해야 합니다.

실행 방법은 README.md를 참고하세요.

## APIM 연결 재점검 (2026-10-15)

- 제공된 게이트웨이 가이드와 공식 API 문서를 대조해 OpenAI Responses, Anthropic Messages, TypeSafe System One 연결을 지원하도록 수정했습니다.
- 최종 오프라인 테스트 229개와 Ruff 검사를 통과했습니다. 여기에는 모의 HTTP를 사용하는 APIM 통합 테스트 13개가 포함됩니다.
- 공급자 원본 키를 보내지 않는 공통 api-key 인증, 함수 스키마 보존, 정상 no-call과 오류 구분, 수정 반복, 정답 유출 방지, 비용/캐시 집계, 재개 및 키 교체를 확인했습니다.
- check-config는 실제 네트워크 요청 0회로 가이드의 OpenAI/TypeSafe 경로를 확인했습니다. 로컬 APIM 키는 비어 있으며, 가이드의 키 값도 자리표시자입니다. 실제 계정 권한과 모델 호출은 검증하지 않았습니다.
- 논문에 실제 기본 API/게이트웨이 구성과 비용 설명을 반영했습니다. 내장 컴파일, PDF의 본문 4쪽+참고문헌 1쪽 검사 및 변경된 본문 전체의 시각 검수를 마쳤습니다.
