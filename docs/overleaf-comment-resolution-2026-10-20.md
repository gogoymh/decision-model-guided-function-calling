## 추가 평가의 고정 범위

계획은 `docs/evaluation/overleaf-experiment-plan-2026-10-20.json`, 데이터 근거는 `docs/evaluation/apibank-firstcall-manifest.json`, 세부 절차는 `docs/overleaf-extra-evaluation-protocol.md`에 있습니다.

- **API-Bank:** 공식 given-description 폴더의 214개 대화 중 첫 API 호출이 있는 212개를 점검했습니다. `device_id`/`name`의 정답과 도구 스키마 충돌 8개를 사전 제외해 204개를 준비했고, 유사 대화 묶음을 유지해 개발 48개·평가 156개로 분리했습니다. 개발 48개는 결과 기반 튜닝에 사용하지 않습니다.
- **방법:** BFCL에서 사용한 `r=3`, 임계값 0.5, 예산 소진 시 최초 후보 유지 규칙을 그대로 전이합니다. 한 생성 모델·한 반복 안에서 Direct와 DMFC가 최초 후보를 공유합니다. 생성 모델이 달라지면 각 모델이 별도 최초 후보를 생성합니다.
- **평가:** API-Bank는 고정 53개 도구 목록을 주고 첫 호출의 이름·정규화한 인자 일치를 실행 없이 평가합니다. 전체 API-Bank 공식 실행 점수·대화 성공률로 표현하지 않습니다. BFCL 주 정확도 분모는 3,035개이며 추가 실험도 이 분모를 유지합니다.
- **제한:** 한 검증 모델, BFCL 평가 결과를 보고 선택했던 설정, 작은 API-Bank 전이 표본, API-Bank에 no-call 정답이 없는 점을 남깁니다. 세 번 반복한 156개를 독립 사례 468개로 세지 않습니다. 기존 F/A/L ablation과 지연시간 연장 경로는 한 번의 기록입니다.

API-Bank 입력 호환성: Claude가 assistant 메시지로 끝나는 원본 대화를 거부해, 결과 수치를 열어보기 전에 공통 지시문을 모든 모델의 입력 끝에 추가했습니다. 원래 대화·정답·도구·분할은 유지했습니다. 처음 시도는 인터페이스 점검 기록으로 보존하고 최종 비교에서 제외합니다. 사전 변경 기록은 docs/evaluation/apibank-interface-amendment-2026-10-20.json에 있습니다.

추가 변경 이력: 첫 공통 지시문에서 GPT가 호출 후보를 텍스트로만 설명해, 실제 결과를 확인한 후 구조화된 후보 출력을 명시했습니다. 개발 예제 4개에서 인터페이스를 확인하고 세 모델의 최종 3회 비교를 시작했습니다. 이전 결과를 본 뒤의 수정이므로 API-Bank 추가 평가는 탐색 평가로 표시합니다.

## 다음에 남는 우선 과제

1. **독립 확인 평가:** 지금의 API-Bank 후보 지시를 고정하고 별도 미사용 데이터에서 세 번 확인합니다. 이전 결과를 보고 입력 형식을 다듬었으므로 현재 결과는 탐색 평가입니다.
2. **다른 검증 모델 계열:** 생성 모델을 고정하고 같은 최초 후보에서 Jev와 일반 LLM 검증기를 비교합니다. 현재 논문의 제목은 Decision Model을 사용하지만, 검증 모델을 여러 계열로 비교한 것은 아닙니다. Jev 1.13/1.14의 버전 비교는 서로 다른 계열 비교가 아닙니다. 다른 전문 decision model을 쓸 수 있는지도 먼저 확인합니다.
3. **오픈 가중치 생성 모델:** 이번 Claude 비교에 이어 Qwen3-4B-Instruct-2507 등을 추가해 공개 가중치 모델로의 전이를 확인할 수 있습니다. 해당 실험은 아직 수행한 결과가 아닙니다.
4. **대화·실행 성공으로 확대:** API-Bank 원래 실행 평가나 StableToolBench·τ 계열의 상호작용 평가를 후속 연구로 고려합니다. 현재 실행 전 첫 호출 평가와 다른 결과 지표이므로 별도 실험 설계가 필요합니다.
5. **제출용 마무리:** 검증된 추가 결과만 넣어 참고문헌·부록까지 총 4쪽을 유지하고 익명 review 형식과 첫 페이지 Web/track 관련성을 점검합니다. 원격 코멘트의 숨겨진 본문은 원래 프로젝트에서 show more를 펼쳐 별도 확인합니다.

## 최종 검증

- API-Bank 세 모델: 각각 936개 방법 기록, BFCL Claude: 18,306개 방법 기록이 모두 완료됐습니다. 기존 BFCL GPT 두 모델의 기록도 그대로 대조했습니다.
- 통합 표는 정확도·표준편차·짝지은 구간·시간·비용을 원본 기록에서 계산했습니다. usage를 받지 못한 방법 기록 7개는 확인된 사용량의 평균 비용에서 제외합니다. 실패 후 저장되지 않은 수정 작업의 비용은 청구 총액처럼 표시하지 않습니다.
- 핵심 실험 코드 해시는 기존과 같습니다. 전체 오프라인 테스트 748개와 코드 검사를 통과했습니다.
- 최종 PDF는 참고문헌까지 총 4쪽이며, 네 페이지를 렌더링해 여백·표·그림·문자 잘림을 확인했습니다. 앱의 단일 파일 컴파일러는 제공된 ACM 클래스의 명령과 여러 파일 프로젝트를 지원하지 않아 기존 설치된 LaTeX로 PDF를 만들었습니다.
- 원격 Overleaf의 Reply/Resolve는 수행하지 않았습니다. 새 소스 ZIP을 원래 프로젝트에 업로드한 뒤 화면 2·3의 숨겨진 본문을 확인해야 합니다.

## 익명 심사본·공개 코드의 후속 정리

같은 날 추가 요청에 따라 현재 `paper/main.tex`와 `paper/main.pdf`를 제공된 ACM `sigconf,anonymous,review` 형식으로 바꿨습니다. 저자·소속·이메일·감사의 글을 제외하고 CCS와 WWW 2027 학회 정보를 넣었으며, 첫 페이지에 Web 문제와 작업 기준 트랙인 Web Infrastructure and Agentic Systems와의 관련성을 적었습니다. 이전 저자 표시 원고는 `paper/versions/2026-10-20-author-review/`에 그대로 보존합니다.

업로드용 소스는 감사의 글을 제외한 **10개**이며, 새 ZIP만 별도 폴더에 풀어 컴파일한 PDF와 현재 저장소 PDF의 본문·4쪽 렌더링이 모두 같습니다. 전체 오프라인 테스트 **768개**와 코드 검사를 통과했습니다. 공개 라이브러리는 `dmfc.DMFC`로 바꾸고 기존 `jbfc` import와 실험 ID를 보존했습니다. 자세한 파일 목록은 [업로드 체크리스트](overleaf-upload-checklist-2026-10-20.md), 이름 변경 범위는 [공개 API 변경 기록](dmfc-public-api-migration-2026-10-20.md)에 있습니다. 실험 수치와 기존 실험 코드 해시는 이 정리에서 바꾸지 않았습니다.
